## contributing

If you want to **contribute**, you can simply improve the description, for example, but here is the complete **list of things you can do to contribute**:

- **improve the description**
- add a page to the site with **real information** about **the universe**
- suggest **things** or **improvements**

And put the details of your improvement in the **[Pull Requests](https://github.com/piratesboys/universe/pulls)**

If you don't know how to create a pull request, here's what to do:

- **Fork** the repository
- Once you're on the cloned repository, modify it and go to **Pull Requests**
- Then click on **New Pull Requests**
- And then follow the steps provided

If you are using AI, please read the **[AI usage policy](https://github.com/piratesboys/universe/blob/main/AI_POLICY.md)**
